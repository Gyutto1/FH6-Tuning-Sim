## 2. v0.5 目标

```
让每一次 run 不再是 session_id / CSV 文件名，
而是车辆数据库中一个可编辑、可搜索、可标注的数据对象。
```

具体产出：

1. **QComboBox 白字修复** — 所有下拉框文字可见
2. **车辆编辑** — 车辆库可编辑车辆名称、PI、驱动形式
3. **标签库可编辑** — 新增/编辑标签，无需手动填写 tag_key
4. **Run 列表可读** — 显示用户可读标题（车辆名 + 路线 + 类型）
5. **Run Library 页面** — 全局数据总览，支持按车辆/路线/类型/标签/关键词筛选
6. **Record Run 标签联动** — 意图标签从标签库读取，可快速新建
7. **零侵入** — 不修改 parser/UDP listener/raw schema/Streamlit

## 4. 数据结构兼容策略

保持 JSON index 不变，不迁移 SQLite。

### platform_index.json 写操作

`update_car(car_id, fields)` 内部调用 `platform_store.write_platform()`：

```python
def update_car(self, car_id: str, updates: dict) -> bool:
    platform = read_platform()
    car = find_car(platform, car_id)
    if not car:
        return False
    for k, v in updates.items():
        if k in ('display_name', 'performance_index', 'drivetrain', 'notes', 'status'):
            car[k] = v
    write_platform(platform)
    self._platform = None  # invalidate cache
    return True
```

### 标签新增/编辑

标签存储在两处：`configs/dictionaries/<category>.json`（字典文件）和 `annotation_store`（运行标注）。v0.5 只操作字典文件：

```python
def add_tag(self, category: str, key: str, label_zh: str) -> bool:
    items = read_dictionary_items(category, include_inactive=True)
    items.append({"key": key, "label_zh": label_zh, "is_active": True})
    write_dictionary_items(category, items)
    return True
```

### Run 搜索/筛选

不建数据库索引，直接在内存中过滤 `runs_index.json`（当前 4 条 run，性能无影响）：

```python
def search_runs(self, car_id="", route="", run_type="", tags=None, keyword="") -> list[dict]:
    runs = self._load_runs()
    result = runs
    if car_id:
        result = [r for r in result if r.get('car_id') == car_id]
    if route:
        result = [r for r in result if route in r.get('route_name', '')]
    # ... etc
    return result
```

## 9. 回滚/风险控制建议

1. **每完成一个 Subtask 立即 git commit**（如用户允许），便于定位问题和回滚
2. **platform_index.json 写入前自动备份**：`data/platform/platform_index.json.bak.{timestamp}`
3. **字典 JSON 写入前自动备份**：`configs/dictionaries/*.json.bak.{timestamp}`
4. **不可恢复性操作（数据删除）一律用 archive/disable 代替 hard delete**（已有 `is_active` 字段和 `status: "archived"` 设计）
5. **如发现会破坏 parser / UDP listener / raw schema 的修改，立即停止**
