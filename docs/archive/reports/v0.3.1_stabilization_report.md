# FH6 Tuning Sim v0.3.1 Stabilization Report

## 1. Summary
本轮完成的是 v0.3.1 稳定化，不是 v0.4 功能扩张。

已完成：

- 增加轻量 UI helper，并小范围收敛 Dashboard、车辆详情、路线详情、开始记录、记录回顾的信息层级。
- 增加安全 JSON store helper，现有 store 入口保持兼容。
- 增加 Route Profile / Survey readiness，用于描述用户测得的安全行驶走廊草稿准备度。
- 增加数据完整性检查和报告，所有问题作为 warning，不阻止 UI 启动。
- 增加稳定化单测并完成回归验证。

未做：

- 未重写 Streamlit app 或导航系统。
- 未修改 CLI、UDP listener、packet parser、raw telemetry CSV 格式或 feature engineering 管线。
- 未实现 AI 训练、强化学习、自动调校优化、复杂边界融合、完整赛道进度算法、3D 可视化或 SQLite 迁移。

## 2. Changes by Agent

### Agent A：UI/UX
- 新增 `fh6_tuning_sim/ui/theme.py`，只包含轻量 Streamlit helper：section header、metric card、status badge、empty state、advanced expander。
- 精简现有 CSS，移除大面积渐变背景和高圆角卡片，保持低风险、低侵入。
- Dashboard 增加最近记录和下一步建议。
- Route Detail 增加 readiness 提示、survey 过滤和高级折叠的 Route Profile 草稿生成。
- Record Run 将 UDP host/port 放入高级设置，主流程更接近车辆、调校、路线、Data Out 检查的向导顺序。
- Run Review 将质量 JSON、laps、状态计数放入高级折叠区。

### Agent B：Store
- 新增 `json_store.py`，提供 `ensure_parent_dir()`、`safe_load_json()`、`safe_save_json()`。
- 新增 `car_store.py` 和 `route_store.py`，作为轻量、兼容的 store 边界。
- `platform_store.py`、`run_index.py`、`annotation_store.py`、`route_profile.py`、`dictionaries.py` 的读写入口改为安全 JSON helper。
- 未拆分 Tune / Dataset Group，避免本轮扩大 store 重构范围。

### Agent C：Route Profile
- 新增 `route_survey_readiness(route_name, survey_runs, profiles=None)`。
- Readiness 规则：
  - `not_started`：没有左/右/参考线测量。
  - `insufficient`：测量不足。
  - `draft_available`：左边界 >= 3、右边界 >= 3、参考线 >= 1。
  - `complete_enough`：左边界 >= 5、右边界 >= 5、参考线 >= 3。
- 增加 `route_readiness_status` 数据字典。
- 文案限定为用户测量的安全行驶走廊草稿，不宣称官方 FH6 赛道边界或 checkpoint 校验。

### Agent D：Integrity / Archive
- 新增 `integrity.py`，检查孤立 run、孤立 annotation、缺失文件、缺失 Route Profile source run、重复 ID、无效 tag_id。
- 生成 `reports/data_integrity_report.md`。
- 当前工作区完整性检查结果：0 条 warning。
- 本轮不做 hard delete UI；继续保留 archive/disable 策略。

### Agent E：Tests
- 新增 `tests/test_stabilization.py`。
- 覆盖安全 JSON、Route readiness 阈值、integrity warning/report。
- 回归验证见第 4 节。

## 5. Remaining Risks
- UI 仍是单文件 Streamlit app，信息架构已收敛但还没有做组件级拆分。
- Store 只做了轻量边界整理，Tune / Dataset Group 仍留在 `platform_store.py`。
- Route Profile readiness 只检查测量数量，不做边界融合、路线合法性或 checkpoint 校验。
- Integrity check 当前是 warning/report 层，不阻止用户继续操作。
- `git` 在当前 shell 中不可用，因此未能用 Git 状态辅助核对工作区差异。
