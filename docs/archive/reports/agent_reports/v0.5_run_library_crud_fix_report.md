# v0.5 Run Library 筛选 + CRUD 修复报告

时间：2026-05-30

## 1. 问题根因

| 根因 | 影响 |
|------|------|
| Run Library 仅有 2 个筛选控件（车辆 + 关键词） | 无法按路线/类型/标签/质量筛选 |
| `search_runs` 未做 label→key 映射 | 中文标签无法匹配 |
| 无 `list_run_records` 标准化层 | raw JSON 字段直接暴露给 UI |
| 无 run 级 CRUD 接口 | 无法编辑备注/标签/归档 |
| 所有 run 字段为 legacy 默认值 | 筛选实际无数据可区分 |

## 2. 当前 tag/run metadata 存储位置

| 存储位置 | 字段 | 用途 |
|---------|------|------|
| `runs_index.json` → `tags: []` | tag_key 数组 | 主存储（CRUD 操作对象） |
| `runs_index.json` → `intent_tags: []` | tag_key 数组 | 历史兼容 |
| `annotations.json` | tag_ids + metadata | 注解层（同步写入） |
| `data/index/tags.json` | 用户标签定义 | 新建标签存储 |
| `configs/dictionaries/` | 系统标签定义 | 只读 |

## 3. 标准化 run record 字段

```python
{
    "run_id", "session_id", "display_title",
    "car_id", "car_name",
    "tune_name",
    "route_name", "route_mode",
    "record_type", "record_type_label",
    "tag_keys",
    "quality_status",
    "duration_seconds", "created_at", "notes",
    "search_text",
}
```

## 4. 筛选函数说明

`filter_run_records(records, car_id, route_mode, record_type, tag_keys, quality_status, keyword, tag_match_mode="AND")`

- 纯函数，不依赖 GUI
- 多条件 AND 组合
- 标签 AND 匹配（`tag_keys.issubset(record.tag_keys)`）
- 关键词搜索 `search_text`（大小写不敏感，中文支持）

## 5. Run metadata 编辑方案

| 操作 | 函数 | 备份 |
|------|------|------|
| 编辑备注 | `update_run_notes(session_id, notes)` | `.bak.{ts}` |
| 添加标签 | `add_tag_to_run(session_id, tag_key)` | `.bak.{ts}` |
| 移除标签 | `remove_tag_from_run(session_id, tag_key)` | `.bak.{ts}` |
| 归档 | `archive_run(session_id)` → status="archived" | `.bak.{ts}` |

## 6. Run tag 添加/移除方案

- 主存储：`runs_index.json` 的 `tags` 数组
- 同步写入：`annotation_store.upsert_annotation()`（注解层）
- UI：QInputDialog 选择已有标签（显示 label_zh）

## 7. 归档方案

- `archive_run()` 设置 `status: "archived"`, `is_active: False`
- `list_run_records(include_archived=False)` 默认过滤已归档
- 原始 CSV / metadata 文件不删除

## 8. UI 改动

**Run Library 页面（完全重写）：**

- 筛选行 1：车辆 + 路线模式 + 记录类型 + 质量状态（4 个下拉）
- 筛选行 2：关键词搜索 + 标签下拉 + 清空筛选按钮
- 结果卡片：display_title + subtitle + tag chips + 4 个操作按钮
- 操作按钮：编辑备注 / + 标签 / - 标签 / 归档
- Empty state：中文提示
