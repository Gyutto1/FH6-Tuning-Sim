## 5. tag 是 tag_id、tag_key、label_zh 还是纯文本

- `runs_index.json` 中使用 `tags: []` (字符串列表) 和 `intent_tags: []` (字符串列表)
- `tags` 存储的是 **tag_key**（如 "baseline", "full_lap"）
- `label_zh` 通过 `dictionaries` 模块从 tag_key 查找
- 当前所有 run 的 `tags` 和 `intent_tags` 均为空，无法测试标签筛选

## 6. route 是 route_id、route_name 还是 unknown

- `route_name` 存储纯文本字符串
- 当前 4 条 run 全部是 `"unknown"`
- 不存在 `route_id` 字段
- 不存在 `route_mode` 字段

## 7. tune 是 tune_id、tune_name 还是 unknown

- `tune_name` 存储纯文本（"stock_default", "baseline_001"）
- `tune_version` 存在但为空字符串
- 不存在 `tune_id` 字段
- `platform_index.json` 中有 `tune_versions` 列表

## 9. 为什么指定筛选条件没有生效

### 根因 1：UI 缺少筛选控件
当前只有车辆下拉和关键词搜索。路线、记录类型、标签、质量、调校、清空按钮全都没有。

### 根因 2：run 数据字段全为默认值
- `route_name` 全是 "unknown" → 路线筛选无意义
- `run_type` 全是 "normal_recording" → 类型筛选无意义
- `tags` / `intent_tags` 全空 → 标签筛选无意义

### 根因 3：search_runs 未做标签映射
`search_runs` 的 `tags` 参数匹配的是 raw tag_key，但 UI 显示的 `label_zh` 无法反向查找。

### 根因 4：run_display_title 输出不可读
`run_display_title` 生成 "Mercedes-AMG GT · unknown · normal_recording"，用户看到的是 technical 内部 key 而非中文标签。

新增 `list_run_records()` 将每条 raw run 转换为标准化 UI record：

```python
def list_run_records(self) -> list[dict]:
    records = []
    for r in self._load_runs():
        records.append({
            "run_id": r.get("session_id"),
            "session_id": r.get("session_id"),
            "display_title": self._build_display_title(r),
            "car_id": r.get("car_id", ""),
            "car_name": r.get("car_name", "未知"),
            "tune_name": r.get("tune_name", "未设置"),
            "route_name": r.get("route_name", "未设置"),
            "route_mode": self._infer_route_mode(r),
            "record_type": r.get("run_type", "unknown"),
            "record_type_label": self._type_label(r.get("run_type", "")),
            "tag_keys": (r.get("tags") or []) + (r.get("intent_tags") or []),
            "quality_status": r.get("quality_status", "unknown"),
            "duration_seconds": r.get("duration_seconds", 0),
            "created_at": r.get("created_at", ""),
            "notes": r.get("notes", ""),
            "search_text": self._build_search_text(r),
        })
    return records
```
