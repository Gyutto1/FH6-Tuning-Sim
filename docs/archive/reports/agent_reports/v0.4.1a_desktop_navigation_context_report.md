# PySide6 v0.4.1a：车辆卡片导航 + 记录前上下文选择 报告

更新时间：2026-05-30

## 1. 本轮修复了什么

### Bug 修复

**Bug 1 — cars_page.py lambda 信号捕获错误（关键修复）**

`QPushButton.clicked` 信号携带 `checked=False` 参数，原 lambda 写法：
```python
lambda cid=car_id: self._handle_enter(cid)
```
`checked=False` 作为首个位置参数覆盖了 `cid` 的默认值，导致传给 MainWindow 的 `car_id` 实际为 `False`（bool），因此"进入车辆"和"开始记录"按钮都无法正确导航。

**修复：** 所有 lambda 添加 `checked=False` 前缀参数吸收信号参数：
```python
lambda checked=False, cid=car_id: self._handle_enter(cid)
```

**Bug 2 — car_detail_page.py `lambda:` 零参数冲突**

`lambda:` 不接受任何参数，但 `clicked` 信号传入 `checked=False`。修复为 `lambda checked=False, cid=car_id: ...`。

## 2. selected_car 状态如何传递

```
CarCard 按钮 (car_id 通过 lambda 默认值捕获)
  → CarsPage._handle_enter(car_id)
    → MainWindow._enter_car(car_id)
      → MainWindow._current_car_id = car_id
      → CarDetailPage.load_car(car_id)
      → StackedWidget 切换到 car_detail 页

CarCard "开始记录" 按钮
  → MainWindow._enter_record(car_id)
    → RecordRunPage.load_car(car_id)
    → StackedWidget 切换到 record 页
```

**防护：** `_enter_car` 和 `_enter_record` 均添加 `isinstance(car_id, str)` 检查，防止非字符串值传入。

## 3. 车辆卡片按钮如何连接页面

`CarCard` 接收 `on_enter` 和 `on_record` 两个 callable，分别连接到"进入车辆"和"开始记录"按钮的 `clicked` 信号。

`CarsPage._build()` 为每辆车创建卡片时，用 `lambda checked=False, cid=car_id:` 闭包捕获当前车辆 ID，调用 `_handle_enter(cid)` / `_handle_record(cid)`，后者再调用 MainWindow 注入的回调。

`CarDetailPage` 中的"开始新记录"按钮同理，使用 `lambda checked=False, cid=car_id:` 闭包。

## 4. Record Run 记录前上下文字段

### 完整字段列表

| 字段 | 控件 | 来源 | 备注 |
|------|------|------|------|
| 当前车辆 | QLabel 静态显示 | `car.display_name` + PI + drivetrain | 不可编辑 |
| 路线模式 | QComboBox | 计时赛 / 路线 · 自由驾驶 · 未设置 | 联动路线名称 |
| 路线名称 | QLineEdit（条件显示） | 用户输入 / 自动"自由驾驶" | 仅"计时赛"模式可见 |
| 记录类型 | QComboBox | 9 种：完整跑圈、自由驾驶、直线加速、重刹测试、低速弯、中速弯、高速弯、赛道测量、其他 | 必选 |
| 数据集组 | QComboBox | 车辆已有数据集组 + "自动归类" | 默认自动归类 |
| 记录意图标签 | QPushButton chips（toggle） | 8 种：正常驾驶、基准、故意推头、故意甩尾、重刹测试、出弯打滑、赛道测量、其他 | 多选 |
| 备注 | QTextEdit | 自由文本 | 可选 |

### 路线模式联动

- **计时赛 / 路线** → 显示路线名称输入框 + 提示"输入路线名称以便后续对比分析"
- **自由驾驶** → 隐藏路线名称、自动设为"自由驾驶"、提示"自由驾驶模式：路线不限"
- **未设置** → 隐藏路线名称、警告"⚠ 未设置路线会降低后续建模价值"、Start 按钮禁用

## 5. Start 按钮状态管理

### 启用条件（三个条件全部满足）

1. `self._car` 存在（已从车辆库选择车辆）
2. `route_key != "unset"`（已选择路线模式，非"未设置"）
3. `type_selected`（已选择记录类型）

### 禁用时提示

| 条件 | 状态文字 | 颜色 |

| 无 car | "未选择车辆" | 灰色 |
| 路线未设置 | "请选择路线模式" | 橙色 |
| 记录类型未选 | "请选择记录类型" | 橙色 |

## 10. 下一步建议

**RecordingController 最小接入** — 本阶段已完成所有记录前上下文字段和状态管理，下一步可在当前 Record Run 页面上接入上一轮已实现的 `RecordingWorker`（`fh6_tuning_sim/ui_desktop/services/recording_worker.py`）。

接入方式：
1. 在 `_on_start` 中创建 `RecordingWorker` + `QThread`
2. 从当前表单字段读取 metadata（路线模式、记录类型、意图标签、备注）传给 worker
3. 恢复状态显示（等待数据 / 记录中 / 已停止 / 错误）
4. 录制完成后调用 `build_run_record` + `upsert_run` 并跳转回 Car Detail
