## 数据结构兼容说明

- **platform_index.json**: `update_car` 仅修改 `display_name`/`performance_index`/`drivetrain`/`status`/`notes` 五个白名单字段，写入前自动生成 `.bak.{timestamp}` 备份
- **tags.json**: 新建 `data/index/tags.json` 存储用户标签，与 `configs/dictionaries/` 系统字典完全隔离。TagLibrary 和 Record Run 读取时合并两者
- **runs_index.json**: 只读，未修改结构。`run_display_title` 和 `run_subtitle` 为纯展示层动态生成，不写回 index
