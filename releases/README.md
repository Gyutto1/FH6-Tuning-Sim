# FH6 Tuning Sim Portable Package (v1.1)

## Package

- File: `FH6TuningSim_portable_v1_1.zip`
- Type: portable `onedir` build
- Platform: Windows x64

## How To Run

1. Download `FH6TuningSim_portable_v1_1.zip`.
2. Extract to any writable folder, for example: `D:\FH6TuningSim`.
3. Open the extracted folder and run:
   - `FH6TuningSim.exe`

## Important Notes

- Keep all extracted files and folders together. Do not move only the EXE.
- The app reads and writes data in the same extracted folder (`data/`, `configs/`).
- If Windows SmartScreen appears, click `More info` -> `Run anyway`.

## Included Content

- Desktop executable (`FH6TuningSim.exe`)
- Runtime libraries
- Default data folder (`data/`)
- Default config folder (`configs/`)
